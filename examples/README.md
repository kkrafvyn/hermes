# HERMES Examples

| Example | Description | Targets |
|---------|-------------|---------|
| [smartfarm](smartfarm/) | Soil moisture, irrigation, telemetry | stm32, esp32 |
| [testapp](testapp/) | CLI-generated template app | all |

## Run

```bash
python sdk/cli/hermes build examples/smartfarm
python sdk/cli/hermes deploy examples/smartfarm
```
